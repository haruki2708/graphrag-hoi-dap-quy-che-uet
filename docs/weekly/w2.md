### Ghi chú tài liệu (đọc trước khi viết, không đoán)

- `anthropic` 2.0.0 → 2.2.0 (ghim 2.2.0): changelog chỉ ghi breaking "API version 2026-10-21"; 2.2.0 thêm message
  threads, báo cáo usage/cost, sửa thông báo lỗi `max_retries`. Chi tiết ở hướng dẫn chuyển đổi API `2026-10-21`
  (platform.claude.com/docs/en/api/migration-2026-10-21). Điểm ảnh hưởng `src/llm/`:
  - `temperature`/`top_p`/`top_k` gửi lên là **400, kể cả giá trị mặc định**; SDK 2.x đã bỏ hẳn 3 tham số → không truyền.
  - Key gửi qua `Authorization: Bearer` (không còn `X-Api-Key`); một client chỉ giữ **một** loại credential → truyền
    `api_key` tường minh.
  - `MessageParam` thành union theo vai; message viết dạng dict `{"role", "content"}` không cần đổi.
  - Đọc từ mã SDK đã cài: API version mặc định `2026-10-21`; retry mặc định 2 lần (0,5–8 s) → đặt `max_retries=0`;
    `messages.create` có `thinking`, `output_config`, `timeout`; có `messages.parse`; lớp lỗi mới `OverloadedError`,
    `ServiceUnavailableError`, `DeadlineExceededError` (đều là `APIStatusError` → xử lý theo mã HTTP).
  - Transport là `httpx2` (khác gói `httpx` mà `google-genai` và NIM dùng).
  - Batch API: changelog 2.x không đổi gì (không làm trong phiên này).
- Claude Haiku 5.5 (tài liệu Claude API): thinking adaptive **bật mặc định** và **tính vào `max_tokens`** (cap nhỏ có thể
  hết token trước khi có chữ); effort mặc định `medium`; `thinking: disabled` chỉ được ở effort ≤ `high`; đọc content
  block theo `type`; prefill → 400; **structured output có** (`output_config.format` `json_schema`, có trên Claude API);
